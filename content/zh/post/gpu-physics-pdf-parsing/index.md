半导体物理与集成电路研究中，大量核心参考资料是扫描版经典教材、国标检测规范和学位论文。如果公式、上下标和表格无法高保真提取，大模型就很难真正辅助物理推导与参数核对。

### 1. 两条本地无云上传路线实测对比
在坚持**全本地运行、不改动原文件并校验 SHA256** 的前提下，我们在本地 RTX 4070 Ti SUPER（16 GB）上，分别用 **749 页扫描版教材**（《模拟 CMOS 集成电路设计》第 2 版）与 **797 页碲镉汞测试参考资料**（含国标与学位论文）对比了两条路线：

| 路线 | 产出形式 | 优势 | 局限 |
|---|---|---|---|
| **OCRmyPDF + EasyOCR（GPU）** | 原样保留像素 + 隐藏文字层 PDF | 逐页像素与原书完全一致，适合原版翻阅检索 | 扫描中文正文与装饰字体错字较多，公式与上下标复制易错 |
| **本地 GPU MinerU（64 页滑窗分批）** | 结构化 Markdown + JSON + 图表 | LaTeX 公式、表格与章节层级保留好，直接适配 LLM 知识库 | 属于重排 Markdown，不保留原扫描页图像叠加 |

### 2. 实测性能与工程建议
- **吞吐与显存**：在 RTX 4070 Ti SUPER 上，本地 MinerU 以 64 页滑窗批处理 **6 份共 797 页 PDF 仅耗时约 3 分 20 秒**，显存占用约 8 GB。
- **先小样本再整本**：处理大部头教材前先试转前 10 页核验质量，并用结构化元数据检查 `0 .. N-1` 全页覆盖，避免静默漏页。
- **接入物理科研工作流**：将经典教材与检测国标转为保留 LaTeX 公式的 Markdown 后，可直接接入领域知识库，实现与仿真代码、实验参数的交叉核对。
